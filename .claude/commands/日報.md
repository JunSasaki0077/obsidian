今日の日付を確認し、対応するデイリーノートを読んで日報を生成する。

## 手順

1. 今日の日付を確認する（`date +%Y-%m-%d` コマンドを使用）

2. 以下のパスから今日のデイリーノートを読む:
   `/Users/z.jun.j.sasaki/Documents/GitHub/obsidian/仕事/デイリーノート/YYYY-MM-DD.md`
   ファイルがない場合は年月フォルダ内も確認:
   `/Users/z.jun.j.sasaki/Documents/GitHub/obsidian/仕事/デイリーノート/YYYY年M月/YYYY-MM-DD.md`

3. デイリーノートから以下を抽出する:
   - `## 今日やること` セクションの **完了済みタスク**（`- [x]` のもの）
   - 完了済みタスクのサブタスク（`- [x]` のもの）も含める
   - `## 朝会` セクションの内容（参考情報として）

4. 以下のフォーマットで日報を生成する:

```
【日報_YYYY年M月D日】
お疲れ様です。佐々木です。
本日の日報です。よろしくお願いいたします。
■本日の業務

- 完了したタスク1
    - 完了したサブタスク
- 完了したタスク2
```

注意事項:
- 完了していないタスク（`- [ ]`）は含めない
- タスク名はデイリーノートの記載をそのまま使用する
- 親タスクが未完了でも、完了済みのサブタスクは記載する
- 日付の「日」は数字をそのまま使い、先頭のゼロは除く（例: 3月2日、3月17日）

5. 生成した日報を、デイリーノートの `## 日報` セクションに書き込む（既存の内容は保持し、セクション内が空の場合のみ書き込む）

6. 生成した日報のテキストをそのままユーザーに表示する
