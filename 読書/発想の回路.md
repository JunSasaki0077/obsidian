## 要約

#### 問題と課題の違い

問題：今の望ましくない状況のこと
課題：望ましくない状態から理想の状態になるために`やるべきこと`
#### いい企画とは

アイデアは自分勝手で良いが、企画となるとそうはならない

1. ギャップがあるっておもしろいこと
2. 誰かにとって役に立つこと


#### アイデアとは

上手くいかない状態から脱出するための`工夫`から生まれる
工夫は３つの流れから出来ている
```mermaid
 graph TD
	a["うまくいかない"]
	b["別の方法を考える"]
	c["試してみる"]
	
	a --> b
	b --> c
```
この工夫の流れの２番目`別の方法を考える`がアイデアになる

#### 工夫の4K

工夫には４種類ある

1. 改善
   うまくいっていない状態から`今できる調整`をおこなうこと
2. 解決
   結果に注目してうまくいっていない状態を`処理`すること
3. 解消
   うまくいっていない状態の`原因そのものを排除`すること
4. 回避
   うまくいっていないことをやめて`別のことを始める`こと
```mermaid
 graph TD
    ?-->回避;
    理想-->解決;
    原因-->解消;
    現状-->改善;
    subgraph ide1 [今の状態]
    現状;
    原因;
    理想;
    ?;
    end

```


例えば地元で店舗を出しているパン屋さんが悩み事をしています

```mermaid
 graph TD
    c-->解消;
    b-->改善;
    a-->解決;
    ?-->回避;
    subgraph ide1 [今の状態]
    b("`**現状**
    地元のお客さんしか
    こられない`");
    c("`**原因**
    店舗が
    地方にあること`");
    a("`**理想**
    新しい顧客を
    獲得したい`");
    ?;
    end

```

この悩みを4Kを使ってアイデアを出した際に下記の順番で考えていきます
1. 改善
2. 解決
3. 解消
4. 回避

```mermaid
 graph TD
    c-->d;
    b-->e;
    a-->f;
    ?-->g;
    d("解消
    「そもそも店舗があるのが
    いけないのでは？」
    店舗をやめて移動販売")
    e("改善
    「これってもっと地元
    以外で売れないだろうか」
    他地域の店と協業
    販路を増やす")
    f("解決
    「どうやったら新しい
    顧客を増やせるだろう？」
    冷凍パンを
    オンラインで売る")
    g("回避
    「いっそのこと
    パン以外も売ってみる？」
    パンにまつわる
    グッズを販売")
    subgraph ide1 [今の状態]
    b("`**現状**
    地元のお客さんしか
    こられない`");
    c("`**原因**
    店舗が
    地方にあること`");
    a("`**理想**
    新しい顧客を
    獲得したい`");
    ?;
    end

```

この4Kマップがすごい構造が面白いなと感じた、
自分は今回のケースだと解決の冷凍パンをオンラインで売るとしか考えていなかった
**なんで？を大事にしよう**
